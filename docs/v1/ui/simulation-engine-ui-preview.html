What these screens are built to respect

The design commitments a reviewer should check the frames above against.

Provenance & honest absence

  • Provenance is a number's second half. Every projected row and detail carries a SIM / BASE chip adjacent to confidence; it is quiet, monospace, and never absent (RD-1).
  • Provenance is never colour. SIM and BASE wear the same neutral tone; they differ only by label text, so the distinction survives greyscale. No styling makes the newer model look "better."
  • Cannot-project is an answer, not a gap. Insufficient evidence is an amber chip and a plain-English block, ranked last and still selectable — never a blank cell, a zero, or a loading dash (RD-4).
  • Insufficient evidence is a disclosure, not an error. Warning register, never severity="error"; distinct in words and colour from the ordinary "no projection" absence.

Unlike records never share a frame

  • Two models, two records. Baseline and Simulation Engine have separate curves, Brier scores, and sample counts; the model selector defaults to the active model, never lifetime (RD-3).
  • Combined is always labelled. "Sightline lifetime" carries a persistent "spans model versions" caption and is for human reading only — never the readiness input.
  • Compare distinguishes by stroke. Both curves are indigo — Simulation solid, Baseline dashed — with a legend, each labelled with its own Brier and both denominators.
  • No silent fallback. A model with no data for a scope names what it needs; it never borrows the other model's counts or resolves to lifetime.
  • The engine is invisible; its consequences are not. No layer, seed, draw count, or matrix appears — only probability, confidence, provenance, drivers, and each model's record.
