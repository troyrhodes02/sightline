Design handoff · v1.0

Two engines on the same track, graded in plain language — with the ugly evidence one click away and the verdict never touching the throttle.

Model Performance replaces the analytics-first Accuracy surface with Summary → Breakdown → Advanced; Paper Bot replaces the Autonomy sprawl with Performance · Activity · Settings, retires Dry Run, and runs three continuous paper portfolios side by side. Both are admin-only; a viewer's only model-quality context is one track-record block on a contract. The commitment to check every frame against: a difference is never rendered as a decision, and no recommendation surface can change production. Use the Light / Dark switch to flip every product surface.

Note This preview is a rendering of the design, not product code. The application is built in Material UI against the theme; nothing here is copied into it.

What these screens are built to respect

The design commitments a reviewer should check the frames above against.

A difference is not a decision; a recommendation is not control

  • Leader only when earned. A leader is named only when the Brier margin clears 0.01 and the sample clears its floor (50 live / 500 backtest). Receptions reads "too close to call"; touchdowns reads "not enough evidence".
  • No apply button anywhere. The recommendation card offers only "Review selection →". Production changes only through a confirmed human Save on Settings — the one mutation in the feature.
  • Financial ≠ verdict. The leading-by-P&L line always carries the sentence separating money from model quality; the overall leader is driven by probability quality.
  • Readiness never enables trading. Switching the active configuration resets the two-week clock against the new portfolio; nothing on the page can move to real money.

Evidence stays honest; sources stay distinct

  • Two records, never merged. Live and Backtest each carry their own Brier and counts; the summary interprets both without blending them into one score.
  • Each model under its own correction. The Advanced overlay labels Simulation v3 and Baseline v7, each scored under its own recalibration — no shared correction object.
  • Sample size travels with every rate. No probability-bucket rate renders below 30 observations, on the admin surfaces or the viewer block; below-floor buckets are hollow and dashed.
  • Engines by label, not colour. Both engines wear the model accent; Baseline is dashed, Simulation solid, and each figure carries its engine label. Money is neutral; only its sign takes colour.
